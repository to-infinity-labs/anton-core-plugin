# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's private vulnerability
reporting:
[open a report](https://github.com/to-infinity-labs/anton-core-plugin/security/advisories/new).
Do not open a public issue for a vulnerability.

The conversation stays on the private advisory until a fix ships in a signed release.

## Supported versions

Only the latest release is supported; fixes are not backported. The engine updates
itself when the plugin updates, so updating the plugin is how you take a fix.
